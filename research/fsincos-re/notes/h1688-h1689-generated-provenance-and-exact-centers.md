## H1689: exact-center algebra isolates the ROM/rounding interface

For table offset `a=r-b/64=0`, the fixed numerical operators satisfy
`M(0,x)=M(x,0)=0`, `A(0,0)=0` and `T67(0)=0`. Therefore square, sine correction,
cosine correction, and both final correction products vanish. Whatever finite
coefficient values the defined Horner graph has, both unrounded endpoints are
exactly the corresponding native ROM leading words. Only instruction/quadrant
selection, sign and final RC64/C1 remain.

This is a model identity, not a new special-case implementation or fitted
lookup. It is useful because a center test isolates the table leading words
and terminal rounding from the higher-order coefficient graph. It does not
prove the silicon implements either the table or the dispatcher.

fixed M66 reducer: 12 direct and16 reduced, over b=18/22/26/30/36/44. H1689
