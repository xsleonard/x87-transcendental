Date: 2026-09-03

## Why the earlier scans missed the surface

The R1382 comparator split requires the low 72 bits of the right terminal
product to lie in the exact H1463 interval

```text
[0x03aaaaaaaaaaaaaaab, 0x03aaaaffffffffffff].
```

Uniform scans almost always miss this interval.  H1470 factors the positive
Horner result as a monotone step function of the 67-bit fourth-power
significand.  It finds the maximal interval on which that result is constant.
On such an interval the right-product constraint is the linear modular
inequality

```text
LOW <= (fourth * positive) mod 2^72 <= HIGH.
```

An unsigned Euclidean floor-sum counts this set exactly and binary search
locates every solution without scanning the interval.  Every retained fourth
power is then inverted exactly through the fourth-power and first-square chop
maps.  A 200-case brute-force selftest validates the modular counter and first
hit locator.  Sampling chooses which constant plateaus are visited, so the
campaign is not an exhaustive-domain proof.

The first exploratory implementation overstated the final prefilter.  H1463's
six endpoint residues are equivalent to endpoint visibility only inside
d0d0's fixed arithmetic schedule.  Outside that schedule they are merely a
fast prefilter.  H1469/H1470 now emit `PRECANDIDATE`, and H1471 uses the current
incumbent/candidate C builds to decide whether a real software endpoint changes.
The old H1404 Python graph remains an independent check of the square, Horner,
and right-product arithmetic; its endpoint layer is not treated as current
outside the fixed schedule.

H1468's exploratory prefix constraint also omitted square bit 66.  The option
now constrains bits 66 downward and accepts 1--67 prefix bits.  No earlier
prefix timing result is used as evidence.

## Deterministic adversarial bank

With seed `0x243f6a8885a308d3`, the 15,000,000-plateau H1471 campaign reached its
32-pre-candidate limit at iteration 9,000,163.  Both exact square inversions and
the independent Python arithmetic replay pass for all 32.  Current-source C
replay classifies sixteen as genuine R1382 software endpoint separators:

| Changed architectural modes | Operands |
|---|---:|
| RN | 6 |
| RU | 4 |
| RD and equivalent positive-result RZ | 6 |
| No current-source endpoint difference | 16 |

The bank spans 26 intermediate arithmetic-schedule classes.  H1404's older
endpoint layer agrees with the current source on 30/32 rows; both disagreements
are preserved rather than normalized away.  Every genuine separator has the
actual R1272 merge gate enabled.  These are model discriminators only: hardware
may select the incumbent endpoint, the R1382 endpoint, or another result.

Two additional fixed-schedule runs used disjoint seeds and sampled 5,000,000
plus 20,000,000 positive-Horner plateaus.  They reduced 5,122,979 exact modular
hits to 21,444 exact external operands and 88 reduced prefilter hits, but found
zero d0d0-schedule hits.  This is a bounded negative search result, not a
uniqueness claim.

## The former UNKNOWN relaxed-gate query is SAT but nonphysical

One H1471 pre-candidate has d0d0's complete arithmetic schedule:

```text
operand  3ffc:d0001749ed75344d
square   0x548012ec11fe6980b
fourth   0x6f9131f7651bff7ba
```

H1473 fixes this operand directly in the original H1410 external-input graph.
It is SAT in under one second, all 21 pre-tree arithmetic values equal the
independent concrete replay, and the relaxed `merge_gate=1` graph changes RD
and RZ.  The exact P5 tree replay instead gives `merge_gate=0`; current and
candidate `rd3`, retained correction, and all four architectural endpoints are
then identical.

Thus the formerly bounded-UNKNOWN H1410 relaxed-gate second-preimage query is
now constructively SAT.  Its first recovered external assignment fails the
mandatory exact-tree replay and is not an R1382 separator.  This sharpens the
boundary without validating or falsifying R1382 on the sixteen true software
separators.

## Frozen one-shot challenges

H1472 selects one nonredundant FCOS tuple for each of the sixteen true software
separators: six RN, six RD, and four RU.  Repository-visible evidence outside
the source bank and the locally merged private supplemental ledger both have
zero operand collisions.  The manifest state is `FROZEN_UNOPENED`, and each
tuple permits at most one observation.  RZ is omitted where it is the same
positive-result rounding experiment as RD.

The remote capture was not executed.  Copying and executing the project-built
binary on the external root account requires explicit user authorization.  No
attempt was made to bypass that boundary.

## Accepted boundary

This investigation overturns any inference that d0d0 is globally unique as a
software R1382 endpoint separator, and it resolves the relaxed-gate H1410
query to a replay-rejected SAT assignment.  It does not supply hardware labels
for the sixteen new separators and therefore does not validate a general s4
selector.  The ledger-free emulator frontier remains eleven rows over ten
operands; R96 remains empirical/incomplete and R1382/QX/Q remain default-off.
